# Банковское приложение

Банковское приложение с маскироовкой банковских карт и аккаунтов. Фильтрация и сортировка банковских операций. 

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/NikitaGamza/pyCharm.git

2. Установка зависимостей:
    ```bash
   pip install
Список пакетов:
- flake8,
- black,
- isort,
- mypy
- pytest

3. Запуск тестирования
   ```bash
   pytest
