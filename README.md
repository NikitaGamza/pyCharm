# Банковское приложение

Банковское приложение.
Приложение содержит: 
- Маскироовку банковских карт и аккаунтов. 
- Фильтрация и сортировка банковских операций. 
- Генерацию новых банковских карт.
- Фильтрацию по заданным валютам.
- Вывод описания транзакций.

Под каждую функцию прописаны тесты.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/NikitaGamza/pyCharm.git

2. Установка зависимостей:
    ```bash
   pip install
Список пакетов:
- flake8,
- black,
- isort,
- mypy
- pytest

3. Запуск тестирования (tests)
   ```bash
   pytest
   
4. Для запуска отдельных тестов используйте команду
   ```bash
   pytest tests/ИМЯ_ФАЙЛА.py
